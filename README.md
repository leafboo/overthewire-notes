## Bandit 23 -> 24
**Linux Signals** 
- A signal is something sent to a program that makes it stop, quit, pause, or handle the event in some way. To see the list of signals, execute `kill -l`
- To send a signal to a program, execute `kill -[signal] [processId] `. For more info, go to the [man page](https://man7.org/linux/man-pages/man1/kill.1.html)
